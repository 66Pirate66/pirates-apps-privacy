# Pirates Apps Datenschutz

Public GitHub Pages site for app-specific privacy policies. This repository contains public website files only. No app source, APKs, credentials, NAS details or private test data belong here.

- Family index: /
- Pirates Music: /music/ (German and English)
- Website hosting privacy: /website/

GitHub Pages publishing source: main branch, root directory. Files are static HTML/CSS, with no scripts or external embeds.

The Music policy is based on Pirates Music Android 1.0. Keep the app, the published policy and Google Play Data safety disclosures consistent when features change. Add another app only after checking that app’s data handling, providers and permissions. Do not copy Music statements blindly to other apps.
